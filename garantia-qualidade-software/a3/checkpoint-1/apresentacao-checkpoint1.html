02 · Documentação de configuração

Do clone ao ambiente rodando

Requisito de BIOS: Virtualization habilitada — necessária para Docker e WSL funcionarem no Windows.

Clonar spring-petclinic-angular e rodar npm install na pasta — instala as dependências e gera o package-lock.json.

Habilitar a Virtualization na BIOS da placa-mãe.

Clonar spring-petclinic-rest; instalar o WSL se ainda não estiver presente (o Docker Desktop guia os passos).

Subir o backend containerizado via Docker.

$docker run -p 9966:9966 springcommunity/spring-petclinic-rest
## API disponível em localhost:9966
