# Atividade 5 — Matriz de Rastreabilidade

**Status:** ⏳ pendente (depende da Atividade 4)

**Objetivo:** construir uma Matriz de Rastreabilidade relacionando Requisitos → Critérios de Aceitação → Casos de Teste → Prioridade.

**Formato:** dupla, entrega individual no Ulife, PDF, 40 min.

## Etapas

1. Revisão da Atividade anterior — revisar os critérios de aceitação elaborados
2. Construção da Matriz — preencher com requisitos, critérios, casos de teste e prioridade
3. Atribuição de Prioridade — classificar cada requisito: Alta / Média / Baixa
4. Verificação de Cobertura — identificar requisitos sem critérios ou casos de teste associados

## Template

| Requisito | Critério de Aceitação | Caso de Teste (CT) | Prioridade | Status de Cobertura |
|---|---|---|---|---|
| RF-001 | CA-01 | CT-001 | Alta | ✓ Coberto |
| RF-001 | CA-02 | CT-002 | Alta | ✓ Coberto |

## Matriz de Prioridade (referência)

| Prioridade | Critério | Exemplo |
|---|---|---|
| **Alta** | Funcionalidade essencial; impacta diretamente o usuário; risco de segurança; requisito crítico para o negócio | Autenticação, finalização de compra, segurança de dados |
| **Média** | Funcionalidade importante, mas não crítica; há workaround possível | Filtros de busca, notificações por e-mail |
| **Baixa** | Funcionalidade complementar; melhoria de usabilidade; aspecto estético | Cor de botões, ordenação de listas |
